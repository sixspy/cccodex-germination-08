# 发芽口径核算台

种子检验室按书面口径给批次出数。现行口径的分母是播种粒数减去霉粒数，分子是发芽粒数。旧口径把霉粒留在分母里。核算员可以按现行口径再出一版，旧版数字仍留在记录里。

## 技术栈

| 层 | 选型 |
|----|------|
| 接口 | Python Bottle + Waitress |
| 页面 | Svelte 4，无组件库 |
| 数据库 | PostgreSQL 16 |

## 归档与撤回语义

- 出数（归档）按**整批统一裁定**：口径校验、台账写入、批次状态更新在同一事务内，验收不过整笔不入册，不存在半截台账。
- 同一批次同一口径重复归档时跳过并计数（响应里的 `skipped`），数据库层有 `(trial_id, protocol_version)` 唯一索引兜底，禁止双轨入册。
- 并发归档同一批次时，批次行锁（`SELECT ... FOR UPDATE`）让请求排队写入；抢锁失败的后手有限次重试，仍失败返回 `409` 显式争用提示，绝不静默覆盖。
- 撤回接口 `POST /api/trials/<id>/rollback`（仅核算员）：
  - `{}` 或 `{"keep_valid": false}`：整笔撤回该批次全部台账，批次回到待重算。
  - `{"keep_valid": true}`：用当前床次数据重新裁定每条记录，不合格的整条剔除、合格的保留。
  - 撤回后批次列表状态按台账自动重算对齐。
